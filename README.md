# Shelter Management Platform — Demo Ready

Web-based academic prototype for managing shelters, displaced families, humanitarian assistance, and reports for displaced communities in Sudan.

## Demo Login
Email: admin@shelter.com

## Features
- Login interface
- Dashboard with live statistics
- Shelter registration, search and delete
- Displaced family registration, search and delete
- Humanitarian assistance records
- Reports and print/save report
- Responsive layout for phone/tablet/laptop
- Browser localStorage for live demo data

## Deployment
Upload the files to the `main` branch of the GitHub repository and enable GitHub Pages:
Settings → Pages → Deploy from a branch → main → / (root)

This is a front-end academic prototype. It uses browser localStorage and does not contain a production backend or real authentication.
