# 🇸🇩 Shelter Sudan — Shelter Management Platform

A digital platform for coordinating **shelters**, **displaced families**, **humanitarian assistance**, and **operational reports** for displaced communities in Sudan.

Built as an academic graduation project with a distinctive Sudanese visual identity inspired by the Nile, palm trees, and traditional clay architecture.

---

## ✨ Features

- 🔐 **Secure Login** — Simple authentication flow (prototype)
- 📊 **Dashboard** — Overview of shelters, families, capacity, and aid
- 🏕️ **Shelter Management** — Register, monitor, and manage displacement shelters
- 👨‍👩‍👧 **Family Records** — Track displaced families and their essential needs
- 🤝 **Aid Tracking** — Record and monitor humanitarian assistance deliveries
- 📈 **Reports** — Operational insights and printable summaries
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile

---

## 🎨 Design

The interface uses a **Sudanese-inspired theme** featuring:

- 🌴 **Palm tree & Nile wave logo**
- 🗺️ **Sudan map decorative element**
- 🎨 **Earthy palette** — clay brown, gold, Nile green, and cream
- 📐 **Traditional patterns** inspired by Sudanese woven mats
- ✍️ **Elegant typography** — Cormorant Garamond + Inter
